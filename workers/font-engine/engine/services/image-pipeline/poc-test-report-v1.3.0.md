# HandFont Studio 이미지 처리 PoC 테스트 보고서 v1.3.0

## 1. 테스트 환경

- Python 3.11+
- OpenCV 4.13
- NumPy 2.3
- PyMuPDF 1.26
- 기준 출력: A4 150 dpi, 1240 x 1754 px
- 시드: 20260728

## 2. 자동 테스트

총 14개 테스트를 실행했습니다.

- 레이아웃 셀 35개 확인
- 원본 작성 페이지 9장의 등록 마커 검출
- 출력 해상도와 호모그래피 크기 확인
- 문자·유니코드 매핑 확인
- 35개 칸 출력 확인
- 빈 템플릿 35칸의 `missing` 판정 확인
- 합성 필기와 빈 칸 분리 확인
- 등록 마커 누락 입력의 실패 확인

결과: **14개 통과, 실패 0개**

## 3. 합성 촬영 벤치마크

작성 페이지 9장 각각에 다음 6가지 조건을 적용했습니다.

1. 깨끗한 입력
2. 약한 원근 왜곡
3. 회전·밝기 변화
4. 그림자·블러
5. JPEG 압축·노이즈
6. 강한 복합 왜곡

총 54건이며 모든 입력에 합성 필기 8칸을 추가했습니다.

| 지표 | 결과 |
|---|---:|
| 총 케이스 | 54 |
| 성공 | 54 |
| 실패 | 0 |
| 등록 마커 성공률 | 100% |
| 평균 마커 위치 오차 | 0.747 px |
| 마커 평균 오차 95백분위 | 0.849 px |
| 최대 단일 마커 오차 | 1.130 px |
| 평균 셀 모서리 RMSE | 0.751 px |
| 셀 모서리 RMSE 95백분위 | 0.865 px |

위 픽셀 오차는 150 dpi 정규화 좌표계 기준입니다.

## 4. 잉크 분리 샘플

강한 복합 왜곡 샘플을 전체 파이프라인으로 처리한 결과:

- 합성 필기 8칸: `ok` 8칸
- 미작성 칸: `missing` 27칸
- 오검출: 0칸

이 결과는 합성 데이터에 대한 것으로, 실제 펜 번짐과 프린터 농도 편차를 대표하지 않습니다.

## 5. 검증되지 않은 조건

- 여러 프린터의 토너·잉크 농도 차이
- 유광 조명 반사
- 종이 접힘과 비평면 휨
- 등록 마커 일부 가림
- 매우 어두운 남색 외의 유색 펜
- 칸 테두리와 직접 맞닿는 필기
- 저해상도 메신저 재압축 이미지
- 실제 손글씨의 매우 가는 획

## 6. 판정

등록 마커 기반 원근 보정과 고정 레이아웃 셀 추출은 다음 단계에 연결할 수 있는 수준입니다. 잉크 분리는 합성 조건에서는 안정적이지만, 실제 사용자 사진 100장 이상의 파일럿 데이터 없이는 제품 품질로 간주할 수 없습니다.
