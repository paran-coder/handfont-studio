# HandFont Studio 이미지 처리 파이프라인 명세 v1.3.0

## 1. 목표

인쇄용 작성지 한 페이지를 촬영하거나 스캔한 입력에서 다음 결과를 생성합니다.

1. 등록 마커 4개 좌표
2. A4 기준으로 정규화된 페이지 이미지
3. 5x7 작성 칸 35개
4. 각 칸의 실제 작성 영역
5. 템플릿 인쇄 요소를 제거한 필기 잉크 마스크
6. 문자·유니코드·품질 상태를 포함한 JSON

## 2. 좌표계

- 기준 용지: A4 세로, 210 x 297 mm
- 기준 해상도: 300 dpi, 2481 x 3508 px
- 지원 출력: 150, 200, 300, 400 dpi
- 런타임 좌표는 `template-layout-v1.3.0.json`의 정규화 좌표를 출력 해상도에 맞춰 계산합니다.

## 3. 처리 단계

### 3.1 입력 로드

- 이미지 파일은 OpenCV로 디코딩합니다.
- PDF는 PyMuPDF로 지정 페이지를 렌더링합니다.
- PDF 페이지 번호는 1부터 시작합니다.

### 3.2 등록 마커 검출

1. 회색조 및 가우시안 블러
2. 고정 임계값 5종과 적응형 임계값 생성
3. 외곽선 후보 추출
4. 면적, 정사각형 비율, 채움률, 명암 기준 적용
5. 각 모서리 영역에서 최적 후보 선택
6. 네 후보의 크기 일관성과 페이지 사각형 면적 검증

실패 시 자동으로 다른 검은 사각형을 대신 사용하지 않고 오류를 반환합니다.

### 3.3 원근 보정

- 소스: 입력 이미지에서 검출한 등록 마커 중심점
- 대상: 기준 좌표계의 등록 마커 중심점
- 변환: 4점 호모그래피
- 보간: bicubic
- 외부 영역: 흰색

### 3.4 셀 추출

원근 보정 후 고정된 정규화 레이아웃을 적용합니다. 촬영 이미지에서 셀 테두리를 다시 검출하지 않으므로 흐린 회색 가이드나 손글씨가 테두리에 가까운 경우에도 셀 수가 달라지지 않습니다.

- 행: 7
- 열: 5
- 셀: 35
- 작성 영역: 셀 내부의 점선 안전 영역

### 3.5 잉크 분리

1. 입력 작성 영역과 동일 페이지의 빈 템플릿 영역 준비
2. 큰 범위 조명 변화를 평탄화
3. 흰색 기준점 정규화
4. 빈 템플릿보다 새로 어두워진 픽셀 계산
5. 암부 조건과 결합
6. 작은 연결 성분 제거
7. 열림·닫힘 연산으로 노이즈 정리와 획 단절 완화

이 방식은 인쇄된 글자, 유니코드, 중앙선, 점선 안전 영역을 대부분 제거하면서 추가된 검은 필기를 보존하도록 설계했습니다.

## 4. 품질 상태

| 상태 | 기준 | 의미 |
|---|---:|---|
| `missing` | 잉크 비율 < 0.12% | 작성되지 않았거나 검출 불가 |
| `too_sparse` | 0.12% 이상, 0.6% 미만 | 지나치게 짧거나 끊긴 필기 가능성 |
| `ok` | 0.6% 이상, 33% 이하 | 후속 벡터화 대상으로 사용 가능 |
| `too_dense` | 33% 초과 | 번짐, 칸 채움, 잘못된 촬영 가능성 |

임계값은 실제 사용자 필기 데이터 확보 후 문자군별로 재보정해야 합니다.

## 5. 출력 메타데이터

`metadata.json`은 다음 내용을 포함합니다.

- 입력 파일, PDF 페이지, 템플릿 페이지
- 입력·출력 이미지 크기
- 등록 마커 좌표, 신뢰도, 후보 특성
- 호모그래피 행렬
- 전체 상태 집계
- 35개 칸의 문자, 유니코드, 카테고리
- 픽셀 좌표, 잉크 비율, 바운딩 박스, 출력 파일 경로

## 6. 실패 정책

- 마커가 4개가 아니면 자동 생성하지 않습니다.
- 마커 크기나 채움률이 일관되지 않으면 실패합니다.
- 템플릿 페이지는 현재 사용자가 지정해야 합니다.
- 빈 템플릿 자산이 없으면 잉크 분리를 실행하지 않습니다.
