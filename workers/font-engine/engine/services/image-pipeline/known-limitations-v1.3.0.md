# 알려진 한계 v1.3.0

1. 페이지 번호를 자동으로 읽지 않습니다. 사용자가 `template_page`를 지정해야 합니다.
2. 등록 마커 네 개가 모두 보여야 합니다. 세 개 이하에서는 실패합니다.
3. 종이 휨은 평면 호모그래피만으로 완전히 보정되지 않습니다.
4. 잉크 분리는 동일한 빈 템플릿 렌더를 기준으로 합니다. 프린터 출력 특성과 촬영 블러가 크게 다르면 가이드 선 잔상이 생길 수 있습니다.
5. 상태 임계값은 합성 필기 기준이며 실제 필기 데이터로 재보정되지 않았습니다.
6. 자모 분리, 윤곽선 벡터화, 베지어 단순화는 포함하지 않습니다.
7. 색상 필기를 별도 채널로 분리하지 않습니다.
8. 수동 모서리 보정 UI와 서버 API는 포함하지 않습니다.
