# 알려진 한계 v2.0.0

1. 실제 손글씨 촬영본 검증이 없다. 현재 종단 결과는 합성 촬영 세션 기준이다.
2. 480×480 정규화는 글자 전체의 경계 상자를 맞추는 방식이다. 초성·중성·종성을 실제 획 단위로 분리하지 않는다.
3. 자동 조합 8자의 평균 품질 점수는 28.63725/100이며 모두 검수 대상으로 판정되었다.
4. 직접 벡터화와 조합 검증 수를 제한한 smoke test이므로 307자 전체 및 11,172자 전체 처리 성능을 뜻하지 않는다.
5. 실측 처리 시간과 메모리 사용량은 스마트폰 해상도·CPU·벡터화 수에 따라 달라진다.
6. 스타일 슬라이더와 전문 윤곽선 편집기는 통합 CLI에 아직 연결되지 않았다.
7. 최종 폰트 내보내기는 제품 기능으로 분리되어야 한다. v2.0.0은 내부 검증 후 폰트 바이너리를 삭제한다.
8. 한글 조합 품질 개선에는 실제 자모 획 분리, 레이아웃별 다중 샘플, 충돌 최적화가 필요하다.
