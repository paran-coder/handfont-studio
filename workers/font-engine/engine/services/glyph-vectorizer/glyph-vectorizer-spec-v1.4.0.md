# Glyph Vectorizer 기술 명세 v1.4.0

## 목적

v1.3.0 이미지 처리 서비스가 생성한 개별 잉크 마스크를 폰트 빌드에서 재사용 가능한 SVG 윤곽선으로 변환합니다. 원본 캔버스 좌표를 유지하며, 외곽선과 내부 구멍을 한 개의 `evenodd` 경로로 출력합니다.

## 입력 계약

- PNG, JPEG, WEBP, TIFF, BMP
- 회색조, BGR 또는 BGRA
- 권장 형식: 검정 배경에 흰색 잉크인 `ink-mask.png`
- 반전된 검정 잉크·흰색 배경도 테두리 밝기로 자동 판별
- 최소 한 변 16px 이상

## 처리 순서

1. 회색조와 알파 합성
2. Otsu 이진화 또는 사용자 임계값 적용
3. 테두리 중앙값으로 전경 극성 판별
4. 작은 연결 성분 제거와 제한적 closing
5. 0.5 레벨 marching squares 경계 추적
6. 윤곽선 포함 관계와 깊이 계산
7. 둘레 비례 Douglas–Peucker 단순화
8. 각도 기반 코너·곡선 판별
9. 코너는 직선, 곡선은 이차 베지어 `Q` 명령으로 변환
10. `fill-rule="evenodd"` SVG 생성
11. SVG 재래스터화와 원본 IoU 측정
12. 목표 IoU 미달 시 단순화 허용값을 0.75배로 줄여 최대 3회 재시도

## 기본값

| 항목 | 값 |
|---|---:|
| 최소 연결 성분 면적 | 12px |
| closing 커널 | 3px |
| 최초 단순화 허용값 | 둘레 × 0.00085 |
| 곡선 판별 각도 | 110° 이상 |
| 베지어 핸들 비율 | 0.05 |
| 목표 래스터 IoU | 0.90 |
| 최대 재시도 | 3회 |
| 좌표 소수 정밀도 | 2자리 |

## 출력 계약

- `glyph.svg`: 원본 크기의 SVG
- `metadata.json`: 처리 옵션, 유효 허용값, IoU, 노드 수, 윤곽선 계층
- `original-mask.png`
- `vector-raster.png`
- `difference.png`
- `overlay.png`

## 품질 상태

- `ok`: 래스터 IoU 0.90 이상
- `review`: 자동 재시도 후에도 IoU 0.90 미만
- 빈 전경: 단일 처리에서는 오류, 일괄 처리에서는 `skipped`
- 과도한 전경: 배경·전경 반전 가능성이 있어 오류

## 좌표와 채움 규칙

- SVG `viewBox`는 입력 마스크의 폭·높이를 그대로 사용합니다.
- 복수 성분과 내부 구멍은 한 `path`에 여러 닫힌 서브패스로 포함합니다.
- 방향 의존성을 줄이기 위해 `evenodd` 채움 규칙을 사용합니다.
- 이번 버전에서는 y축 반전이나 em-square 변환을 하지 않습니다.
