# 알려진 한계 v1.4.0

1. **원본 좌표계 유지**: SVG는 입력 픽셀 좌표를 사용하며 1000 UPM 폰트 좌표가 아닙니다.
2. **메트릭 미포함**: 기준선, advance width, 좌우 여백과 수직 메트릭을 계산하지 않습니다.
3. **필기 획 구조 미인식**: 윤곽선 기반이므로 중심선, 필순이나 개별 획 의미를 복원하지 않습니다.
4. **아주 작은 구멍**: 최소 성분 면적보다 작은 내부 공간은 제거될 수 있습니다.
5. **강한 노이즈**: 잉크와 비슷한 크기의 먼지·그림자는 별도 윤곽선으로 남을 수 있습니다.
6. **극단적 단순화**: 사용자가 단순화 값을 크게 높이면 코너가 무너지거나 내부 공간이 닫힐 수 있습니다.
7. **SVG 편집 기능 없음**: 잘못된 노드를 브라우저에서 직접 이동하거나 삭제하는 편집기는 아직 없습니다.
8. **실제 사진 검증 제한**: 현재 연동 데이터는 v1.3.0의 합성 촬영 샘플입니다. 다양한 펜·종이·스마트폰 실사진 검증이 필요합니다.
9. **폰트 파일 미생성**: 이번 단계는 SVG까지이며 TTF·OTF는 생성하지 않습니다.
