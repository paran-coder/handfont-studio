# Capture Ingest 기술 명세 v1.8.0

## 목적
스마트폰으로 촬영한 HandFont Studio 작성지를 순서와 파일명에 의존하지 않고 처리하는 수집 계층을 제공한다.

## 입력
- PNG, JPEG, WEBP, TIFF
- 1장 이상의 촬영 파일 또는 폴더
- 선택적 수동 모서리 JSON
- 150/200/300/400dpi 출력 설정

## 페이지 처리
1. 등록 마커 후보 검출
2. 실패 시 파일별 수동 모서리 적용
3. A4 정규 좌표로 원근 보정
4. 작성 영역을 제외한 페이지별 인쇄 차이 픽셀 비교
5. 페이지 1~9 점수 계산 및 최고 점수 선택
6. 마커·페이지 식별·선명도·노출을 결합한 촬영 품질 점수 계산
7. 같은 페이지 촬영본 중 최고 점수 선택

## 페이지 식별
9개 빈 템플릿의 픽셀 분산을 계산해 페이지마다 달라지는 인쇄 문자와 페이지 코드만 식별 마스크로 사용한다. 사용자가 쓴 영역은 비교에서 제외한다.

## 품질 점수
- 등록 마커 또는 수동 좌표 신뢰도: 42%
- 페이지 식별 신뢰도: 30%
- 선명도: 18%
- 노출: 10%

수동 좌표는 자동 마커보다 낮은 기준 계수를 적용해 동일 페이지의 정상 자동 촬영본이 있으면 우선 선택되도록 한다.

## 위치형 커버리지
168개 대표 한글의 셀 상태를 v1.6.0 위치형 매핑과 연결한다.
- `ok`: 정상 제공자
- `too_dense`: 사용 가능하지만 재검수 필요
- `missing`, `too_sparse`: 제공 불가

같은 위치형을 제공하는 대표 글자가 하나라도 정상이라면 해당 위치형은 커버된 것으로 판단한다.

## 결정적 동작
동일한 촬영 파일, 수동 좌표, 설정을 사용하면 페이지 선택과 위치형 보고서의 의미 데이터가 동일하게 생성된다. 처리 시각과 절대 경로 필드는 제외한다.
