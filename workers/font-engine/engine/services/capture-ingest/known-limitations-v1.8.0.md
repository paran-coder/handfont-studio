# Capture Ingest 알려진 한계 v1.8.0

1. 품질 수치는 실제 손글씨가 아니라 합성 촬영 데이터에서 측정되었다.
2. 종이가 심하게 휘어진 경우 단일 호모그래피만으로 완전한 보정이 어렵다.
3. 강한 반사광이 페이지별 인쇄 문자 위에 생기면 페이지 식별 신뢰도가 낮아질 수 있다.
4. 수동 모서리는 페이지 외곽이 아니라 등록 마커 중심 좌표를 입력해야 한다.
5. PDF 다중 페이지 세션 자동 순회는 이번 서비스 범위에 포함하지 않았다.
6. 벡터화 벤치마크는 처리 시간과 패키지 크기를 제한하기 위해 64개 셀만 실행했다. 엔진은 전체 셀 처리를 지원한다.
7. `too_dense` 판정은 위치형 커버리지에 포함되지만 최종 폰트 생성 전 재검수가 필요하다.
8. 실제 스마트폰 기종별 렌즈 왜곡과 자동 HDR 영향은 추가 실측이 필요하다.
