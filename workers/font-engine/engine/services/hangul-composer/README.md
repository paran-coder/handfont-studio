# HandFont Hangul Composer v1.7.0

대표 한글 음절 168자의 위치 영역에서 역할별 마스크 후보를 모으고, 정규화된 마스크 간 평균 IoU가 가장 높은 medoid를 위치형 템플릿으로 선택합니다. 미작성 음절은 정확한 위치형을 우선 사용하고, 누락 위치형은 같은 자모의 가장 가까운 레이아웃으로 변환합니다.

## 실행

```bash
make test
make benchmark
```

벤치마크는 대표 168자를 제외한 음절 500자를 6개 레이아웃 클래스로 층화 선택하고, 마스크·SVG·내부 검증용 TTF를 생성합니다.
