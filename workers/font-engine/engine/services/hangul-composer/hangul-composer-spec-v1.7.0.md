# HandFont Hangul Composer 기술 명세 v1.7.0

## 목적
대표 한글 음절 168자에서 초성·중성·종성 위치형 템플릿을 구축하고, 사용자가 작성하지 않은 현대 한글 음절을 자동 조합한다.

## 입력
- v1.6.0 `hangul-position-map.json`
- 대표 음절 마스크 168개
- 위치형 form ID 175종
- 구성: `L:<자모>:<레이아웃>:<상태>`, `V:<자모>:<레이아웃>:<상태>`, `T:<자모>:<레이아웃>`

## 템플릿 선택
1. 대표 음절의 역할별 위치 영역을 전체 캔버스 마스크로 추출한다.
2. 동일 form ID의 후보들을 전경 정규화한다.
3. 후보 간 IoU 평균이 가장 높은 후보를 medoid로 선택한다.
4. 후보가 하나뿐인 158개 form은 해당 후보를 그대로 사용한다.

이 방식은 픽셀 평균보다 획 두께와 끊김을 잘 보존하며, 대표 168자 재구성 내부 시험에서 첫 후보 선택보다 평균 IoU를 개선했다.

## 조합 규칙
- 정확한 form ID가 존재하면 해당 템플릿을 원래 위치에서 사용한다.
- form ID가 없으면 같은 역할·같은 자모 가운데 레이아웃 거리가 가장 가까운 템플릿을 선택한다.
- 폴백 템플릿은 목표 레이아웃 영역에 종횡비를 유지해 다시 배치한다.
- 구성요소는 이진 OR 방식으로 결합한다.
- 기본 모드는 결정적 정돈형이며, 선택 옵션으로 제한된 위치·크기 변형을 적용할 수 있다.

## 레이아웃 거리
- 동일 레이아웃: 0
- 세로↔복합, 가로↔복합: 1
- 세로↔가로: 2
- 무받침↔받침 상태 변경: 추가 1

## 벤치마크 선택
대표 168자를 제외하고 6개 레이아웃 클래스를 층화해 500자를 선택한다.

| 레이아웃 | 수량 |
|---|---:|
| 세로·무받침 | 80 |
| 세로·받침 | 100 |
| 가로·무받침 | 70 |
| 가로·받침 | 90 |
| 복합·무받침 | 70 |
| 복합·받침 | 90 |

누락 위치형을 사용하는 문자를 먼저 포함해 폴백 성능을 의도적으로 측정한다.

## 품질 지표
- 정렬 IoU: 전경 크기를 정규화하고 ±10px 범위에서 정렬한 뒤 측정
- 정규화 Chamfer 거리: 양쪽 윤곽의 평균 거리
- 밀도 비율: 조합 잉크 픽셀 / 참조 잉크 픽셀
- 최대 구성요소 겹침률
- 캔버스 안전 영역 초과 여부
- SVG 재래스터 IoU

품질 점수는 위 지표를 결합한 PoC용 휴리스틱이며 사용자 선호도나 상업용 글꼴 품질을 직접 의미하지 않는다.

## 출력
- 조합 마스크와 구성 메타데이터
- 비교용 참조 마스크와 오버레이
- SVG 및 contour 메타데이터
- 500자 font-builder manifest
- CSV·JSON 벤치마크 결과
- 내부 검증용 TTF 빌드 보고서와 렌더링 이미지
