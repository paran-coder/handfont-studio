# HandFont Font Builder PoC 테스트 보고서 v1.5.0

## 테스트 환경

- Python 3.11+
- fontTools 4.63.0
- Pillow 12.2.0
- Linux Fontconfig `fc-scan`
- 입력: 프로젝트 문자 세트의 영문 52자, 숫자 10자, 기본 기호 26자
- 입력 형태: 참조 글꼴을 래스터화하고 v1.4.0 벡터화기를 거친 합성 SVG

- cmap·필수 테이블 검증

- 전체 PoC manifest 88자 완전성 검증

## 결정성

동일 manifest, 동일 옵션, 고정 생성 시각으로 두 번 빌드한 TTF의 SHA-256이 일치했다.

## 결과 해석

이번 결과는 SVG에서 설치 가능한 TrueType까지의 빌드 체인이 작동한다는 기술 검증이다. 입력 SVG는 실제 사용자 필기가 아니라 참조 글꼴 기반 합성 데이터이므로, 결과 모양 자체는 손글씨 품질을 평가하는 자료가 아니다.
