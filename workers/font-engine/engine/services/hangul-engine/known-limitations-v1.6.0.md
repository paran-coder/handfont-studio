# 알려진 한계 v1.6.0

1. 입력은 실제 사용자가 작성한 손글씨가 아니라 시스템 참조 글꼴을 래스터화한 합성 검증 데이터입니다.
2. 자모 위치 영역은 레이아웃 기반의 겹치는 사각 영역이며, 연결된 획을 의미적으로 완전히 분리하지 않습니다.
3. 현재 TTF에는 168개 대표 음절만 포함됩니다. 현대 한글 전체 11,172자 자동 조합은 아직 구현하지 않았습니다.
4. 같은 자모의 세부 변형을 통계적으로 보간하거나 대표 형태를 선택하는 알고리즘은 아직 없습니다.
5. 복합 모음은 중성 영역 하나로 취급하며 `ㅗ+ㅏ`, `ㅜ+ㅓ`처럼 내부 요소를 다시 분해하지 않습니다.
6. 실제 손글씨에서는 자모 간 연결, 과도한 기울기, 칸 경계 침범 때문에 영역 추정 정확도가 낮아질 수 있습니다.
7. 폰트 바이너리는 검증 과정에서 내부 생성되지만 배포 패키지에는 포함하지 않습니다.
