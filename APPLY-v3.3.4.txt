2. 압축을 푼 폴더 안의 파일과 폴더를 GitHub Desktop으로 Clone한 handfont-studio 폴더에 복사합니다.
3. 같은 이름의 파일은 모두 덮어씁니다.
4. GitHub Desktop에서 다음 메시지로 커밋합니다.
   Add template downloads and project management v3.3.4
5. Commit to main -> Push origin 순서로 누릅니다.
6. Vercel 자동 배포가 시작되며, 기존 환경변수와 Neon 표는 그대로 사용합니다.
