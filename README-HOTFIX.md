# HandFont Studio v3.3.6 익명 소유권 핫픽스

## 적용

1. 이 ZIP을 압축 해제합니다.
2. 안의 파일과 폴더 전체를 로컬 GitHub 저장소 `handfont-studio` 폴더에 복사합니다.
3. 같은 이름의 파일은 모두 덮어씁니다.
4. GitHub Desktop에서 `Add browser-scoped project ownership v3.3.6`으로 커밋합니다.
5. `Push origin`을 누르고 Vercel 자동 배포가 끝날 때까지 기다립니다.

## 추가 설정

- 새 Vercel 환경변수는 없습니다.
- 새 SQL을 즉시 실행하지 않아도 기능은 동작합니다.
- 트래픽이 늘기 전 `infrastructure/migrations/0002_anonymous_ownership.sql`을 Neon SQL Editor에서 실행하면 조회 인덱스가 추가됩니다.

## 중요

- v3.3.5 이하에서 만든 `owner_id=anonymous` 프로젝트는 보안상 자동 이전하지 않으므로 새 목록에 보이지 않습니다.
- v3.3.6 이후 만든 프로젝트부터 현재 브라우저별로 분리됩니다.
- 브라우저 쿠키나 사이트 데이터를 삭제하면 익명 프로젝트에 다시 접근할 수 없습니다.

## 배포 후 확인

1. 일반 브라우저에서 새 프로젝트를 만듭니다.
2. 시크릿 창으로 같은 사이트를 열었을 때 일반 창의 프로젝트가 보이지 않는지 확인합니다.
3. 일반 창 프로젝트 주소를 시크릿 창에 붙여넣었을 때 404가 표시되는지 확인합니다.
4. 일반 창에서 업로드·삭제·결과 다운로드가 정상인지 확인합니다.
