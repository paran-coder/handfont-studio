## 제한 사항

이 배포 저장소는 과거 버전의 대용량 합성 벤치마크 결과물을 포함하지 않습니다. 따라서 해당 결과물에 의존하는 일부 레거시 회귀 테스트는 CI 대상에서 제외했습니다. 코어 로직과 실제 입력 종단 검증은 별도로 통과했습니다.

현재 실행 환경은 npm 레지스트리 DNS에 접근하지 못해 `pnpm install`과 Next.js production build를 직접 수행하지 못했습니다. GitHub Actions에는 의존성 설치, 테스트, typecheck와 build 단계가 포함되어 있습니다.
