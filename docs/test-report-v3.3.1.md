## 실행하지 못한 검사

현재 실행 환경에서 npm 레지스트리 DNS 접근이 되지 않아 다음 항목을 실행하지 못했습니다.

- `pnpm install`
- `pnpm-lock.yaml` 생성
- Next.js production build

따라서 GitHub 최초 Push 전에 네트워크가 가능한 컴퓨터에서 `pnpm install`을 실행해 lockfile을 생성해야 합니다. GitHub Actions는 이후 `--frozen-lockfile` 설치, 테스트, typecheck와 build를 수행하도록 구성했습니다.
